# PhysicsStudyBuddy · 高中物理智能学习伙伴

> 根据知识点诊断结果生成分阶段学习计划，并通过练习、答疑和复测持续调整计划。

## 项目简介

学生输入科目、年级和知识点，例如“物理／高一／牛顿第二定律”。系统先用三道选择题和两道简答题诊断概念、前置知识与应用能力，再生成包含学习目标、预计用时、完成条件和资源的任务清单。完成任务后可复测，计划随新的答题证据更新。首版聚焦高中物理，适用于自主复习和查漏补缺。

预设示例主题为牛顿第二定律、匀变速直线运动、功与动能定理。也可输入其他高中物理知识点；自由主题的题目与评价未经过项目样例验证，应自行核对。

## 核心功能

1. **诊断**：选择题按固定答案判分；简答题按两个评分要点给 0–2 分，并反馈欠缺之处。能力点显示本轮得分、题数和“需要补基础／需要练习／掌握较好”。这只是当前测验的证据，不代表长期掌握度。
2. **学习计划**：优先补必要的前置知识，再安排讲解、针对性练习和复测。每项任务有预计用时与可观察的完成条件；可标记完成并在复测后重新规划。
3. **学习资源与答疑**：真实模式使用 HelloAgents `SearchTool` 搜索当前任务的学习资源，展示实际搜索结果的标题和链接；辅导智能体回答学生问题。搜索失败时仍可使用计划，并显示提示。
4. **本地进度**：同一学习者与知识点的测验、反馈和计划保存在 `outputs/progress/`，下次运行可继续。该目录已加入 `.gitignore`。

## 技术设计

- **HelloAgents**：诊断智能体生成新题与简答反馈，规划智能体依据逐题结果生成任务，辅导智能体提供答疑；三个角色共用模型客户端，但承担不同职责。
- **结构化输出**：使用 DeepSeek 服务时，题目、评分和计划调用启用 JSON 输出及较低推理量；四项列表选项会转换为 `A`–`D` 格式，非法结果仍会拒绝并重试。其他 OpenAI 兼容服务保留提示词输出方式。
- **Python 工作流**：控制题目顺序、输入校验、选择题判分、逐能力点汇总、进度保存与复测，不让模型自行修改成绩。
- **搜索**：通过 HelloAgents `SearchTool` 的 DuckDuckGo 后端获取结构化结果；仅保存实际返回的 HTTP(S) 链接。搜索结果是学习线索，使用者可检查其内容是否匹配教材。
- **离线演示**：内置经过人工核对的牛顿第二定律示例题和简化关键词评分，无需模型密钥或网络。离线评分仅用于演示工作流，真实模式由诊断智能体按评分要点评价简答。

## 快速开始

建议使用 Python 3.11。进入本目录后安装依赖：

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r requirements.txt
```

Windows PowerShell 可运行离线演示：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
.\.venv\Scripts\python.exe main.py --auto-demo
.\.venv\Scripts\python.exe main.py --demo
```

第一条命令自动演示一轮诊断及计划；第二条提供交互式诊断、计划查看、任务完成标记和复测。离线模式只支持“牛顿第二定律”。`main.ipynb` 提供无需密钥的首轮诊断与复测演示，可用 Jupyter Notebook 顺序运行。

真实模型与联网资源模式需要复制 `.env.example` 为 `.env`，填写 OpenAI 兼容接口的模型名称、服务地址和密钥，再运行：

```powershell
.\.venv\Scripts\python.exe main.py
```

运行时输入昵称、科目“物理”、年级与知识点。交互菜单可查看计划、继续测验、提问、标记任务完成。密钥仅从环境变量读取，不写入项目文件。

## 示例：牛顿第二定律

一名学生在受力分析题中失分，系统会把“补习合力与受力分析”排在计划前面。学生完成该任务并参加不同题目的复测后，如果受力分析得分提高，新计划将不再优先安排该补基础任务。`main.ipynb` 和 `--auto-demo` 会完整展示这个过程。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe main.py --auto-demo
```

测试覆盖诊断与复测、按能力点调整计划、跨运行恢复、缺题拒绝提交、自由主题提示以及资源搜索失败。真实模型的题目质量和简答评分会随模型而变化，建议人工复核用于正式学习的结果。
